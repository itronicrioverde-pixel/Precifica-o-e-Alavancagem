COMO PUBLICAR
1. Suba TODO o conteúdo desta pasta para a raiz do repositório.
2. No GitHub abra Settings > Pages.
3. Em Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
4. Salve.
5. Aguarde o GitHub gerar o endereço do site.

IMPORTANTE SOBRE OS DADOS
Os dados do sistema ainda usam armazenamento local do navegador.
Antes de trocar de endereço ou dispositivo, use "Exportar dados".
Depois, no site publicado, use "Importar" para restaurar o backup.
